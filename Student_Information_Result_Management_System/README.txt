# Student Information & Result Management System

A beginner-friendly university project built with HTML, CSS, and JavaScript.

## Files
- `index.html` — all pages and forms
- `style.css` — layout, colors, responsive design
- `script.js` — student records, marks entry, GPA calculation, search, edit/delete, and LocalStorage

## How to run
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
4. Use the left menu to switch between Dashboard, Add Student, Student List, Marks Entry, Results, and Settings.

## Features
- Dashboard with counts and GPA distribution
- Add, view, search, edit, and delete students
- Enter marks for courses and exams
- Automatic grade and GPA calculation
- Result search and print
- LocalStorage saves data in the same browser
- Export data backup as JSON
- Restore sample data or delete all saved data

## Important notes
- The included student records are sample/demo data. Replace them with your own project data.
- LocalStorage is browser storage, not a real server database. Data does not automatically sync between devices or browsers.
- GPA conversion is a simple example scale for demonstration. Adjust it if your teacher gives a different grading policy.
